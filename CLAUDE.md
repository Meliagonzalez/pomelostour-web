# Proyecto Pomelostour

## Objetivo

Landing page premium para una empresa de rafting.

El objetivo principal es generar reservas por WhatsApp.

## Stack

- React
- Vite
- TailwindCSS

## Arquitectura

src/
    components/
    sections/
    assets/

## Diseño

Inspiración Patagonia.

Mucho espacio.

Fotos grandes.

Componentes reutilizables.

Responsive.

## Reglas

- Usar únicamente Tailwind.
- No crear CSS tradicional.
- No instalar librerías sin pedir permiso.
- Antes de modificar múltiples archivos explicar el plan.
- Mantener componentes pequeños.
- Reutilizar componentes cuando sea posible.
- No romper funcionalidades existentes.
- Después de cada cambio verificar que compile correctamente.
